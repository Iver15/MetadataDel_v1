# MetadataDel

MetadataDel удаляет метаданные из PDF, Word и Excel-файлов. На Windows установщик добавляет пункт **Удалить метаданные** в Проводник, на macOS приложение добавляет Finder Quick Action. CLI подходит для пакетной очистки файлов и папок.

Поддерживаемые форматы: `.pdf`, `.docx`, `.doc`, `.xlsx`, `.xls`.

## Возможности

- Очистка пользовательских и служебных свойств документов: автор, компания, тема, ключевые слова, комментарии, ревизии, сведения приложений и похожие поля.
- Обработка PDF в памяти с повторными попытками записи для сетевых дисков и временно заблокированных файлов.
- Очистка изображений внутри документов без пересжатия: EXIF (в том числе GPS-координаты и модель камеры), XMP, IPTC, комментарии, встроенные миниатюры и данные после конца JPEG.
- Рекурсивная очистка встроенных документов и OLE-объектов (например, книг Excel внутри диаграмм Word).
- Пакетная обработка через SendTo, папки и командную строку.
- Режим аудита: проверка файлов на признаки метаданных без изменения содержимого.
- Опциональные `.bak`-резервные копии перед изменением файлов.

## Быстрый старт для Windows

1. Скачайте `MetadataDel-Setup-<version>.exe` из GitHub Releases.
2. Запустите установщик.
3. Нажмите правой кнопкой на файл или папку и выберите **Удалить метаданные**.

Установщик кладёт в профиль пользователя:

- `MetadataDel.exe`;
- `app.ico`;
- ярлыки и интеграцию с Проводником.

Отдельно устанавливать .NET не нужно.

## Быстрый старт для macOS

1. Скачайте `MetadataDel-<version>-osx-arm64.dmg` из GitHub Releases.
2. Откройте DMG и перетащите **MetadataDel.app** в **Программы**.
3. Запустите приложение оттуда и нажмите **Включить очистку правым кликом в Finder**.
4. В Finder нажмите правой кнопкой на файл или папку и выберите **Быстрые действия** -> **Удалить метаданные (MetadataDel)**.

Интеграция Finder устанавливается без `sudo` в профиль пользователя и работает при закрытом окне:

- `~/.local/bin/metadatadel`;
- `~/.local/bin/mdel`;
- `~/Library/Services/Удалить метаданные (MetadataDel).workflow`;
- `~/Library/Application Support/MetadataDel/finder-action.sh`.

Для публичного релиза DMG нужно подписывать Developer ID и notarize через Apple. Без нотарификации macOS может показать предупреждение Gatekeeper при первом запуске.

Удалите интеграцию через **Настройки → Удалить интеграцию**, затем переместите приложение в Корзину. Подробная инструкция по установке, удалению, Gatekeeper и сборке DMG: [docs/MACOS.md](docs/MACOS.md).

## Как пользоваться

### Один файл

Правый клик на `.pdf`, `.docx`, `.doc`, `.xlsx` или `.xls` -> **Удалить метаданные**.

### Много файлов

Выделите файлы -> **Отправить** -> **Удалить метаданные**.

Этот путь запускает один процесс MetadataDel для всех выбранных файлов и обычно быстрее контекстного меню на большом количестве документов.

### Папка

Правый клик на папке -> **Удалить метаданные**.

MetadataDel рекурсивно обработает все поддерживаемые файлы внутри папки и вложенных папок.

### Окно приложения

Запустите MetadataDel по значку. Перетащите файлы в окно или нажмите **Выбрать файлы**, затем **Очистить**. Рядом с каждым документом появится результат; предупреждения и ошибки можно прочитать отдельно. Папки по-прежнему обрабатываются правым кликом или через CLI.

Резервные копии в окне включены по умолчанию. Этот флажок не меняет существующий правый клик: Finder использует резервные копии, Windows-контекстное меню сохраняет прежний режим без них. Окно не требуется держать открытым для очистки через системное меню.

### Командная строка

```powershell
# Очистить файлы
MetadataDel.exe --log file.pdf document.docx report.xlsx

# Очистить все поддерживаемые файлы в папке
MetadataDel.exe --log "C:\Documents\Reports"

# Создать .bak-копии перед очисткой
MetadataDel.exe --log --backup file.pdf

# Проверить файлы без изменения
MetadataDel.exe --audit file.pdf document.docx

# Сбросить даты файловой системы на 1980-01-01 UTC
MetadataDel.exe --wipe-fs file.pdf
```

## Поддерживаемые форматы

| Формат | Что очищается | Примечания |
|--------|---------------|------------|
| PDF | Info dictionary (остаётся пустой словарь, без Producer и дат), XMP документа, страниц, изображений и форм; PieceInfo и LastModified во всех объектах; EXIF/XMP внутри JPEG и JPEG 2000; аннотации, формы, вложения, закладки, статьи, миниатюры страниц; имена слоёв заменяются на «Layer N»; предыдущие версии файла (инкрементальные обновления); служебный комментарий iText | Документ пересобирается из страниц, поэтому неиспользуемые объекты не переносятся |
| DOCX | Core, Extended и Custom properties, миниатюра, скрытый текст, локальные пути в ссылках и кодах полей, комментарии и их авторы (включая commentsExtensible/commentsIds), ревизии и tracked changes, rsid во всех частях (включая стили и нумерацию), docId, docVars, ссылка на шаблон с локальным путём, источники слияния, настройки принтера, custom XML, пути к исходным файлам картинок, личные исключения из защиты от редактирования; метаданные изображений и встроенных объектов; части архива, на которые нет ссылок | Microsoft Office не нужен |
| XLSX | Свойства книги, миниатюра, скрытые листы без зависимостей, авторы, комментарии и threaded comments, подключения, внешние ссылки, журнал изменений общей книги, автор и дата обновления сводных таблиц, кэш исходных данных сводных таблиц, настройки принтера, absPath, documentId, fileVersion, пути к исходным файлам картинок; метаданные изображений и встроенных объектов; части архива, на которые нет ссылок | Microsoft Office не нужен. Сводные таблицы после очистки обновляются из исходных данных книги |
| DOC | OLE property streams со свойствами документа; копии автора, последнего редактора, заголовка, шаблона и источников слияния во внутренних таблицах Word; даты создания, правки и печати, число редакций, время правки; история сохранений; авторы исправлений и комментариев заменяются на «Unknown», инициалы — на «U», даты комментариев стираются; то же во встроенных объектах; пути вложенных файлов (OLE Package) сокращаются до имени файла; локальные пути в кодах полей (INCLUDEPICTURE, INCLUDETEXT, LINK, HYPERLINK) и в данных гиперссылок заменяются именем файла | Microsoft Office не нужен. Даты отдельных исправлений в тексте остаются. Скрытый текст не удаляется — выводится предупреждение. Зашифрованные документы и Word 6/95 очищаются только от property streams с предупреждением |
| XLS | OLE property streams со свойствами документа; имя пользователя, последним сохранившего книгу (WriteAccess); авторы примечаний заменяются пробелами; свойства встроенных объектов; пути вложенных файлов (OLE Package) сокращаются до имени файла | Microsoft Office не нужен. Если автор вписан в сам текст примечания, он остаётся: это содержимое. Скрытые листы не удаляются — выводится предупреждение. В зашифрованных книгах имена остаются, выводится предупреждение |

Контекстное меню, CLI и обработка папок поддерживают DOC/XLS без установленного Microsoft Office.

Очищенный файл сохраняет права доступа исходного: на macOS — режим файла, на Windows — ACL. Удаление программы стирает и журналы MetadataDel, потому что в них записаны пути очищенных файлов.

## Опции CLI

| Опция | Описание |
|-------|----------|
| `--log` | Записывать лог в `%LocalAppData%\MetadataDel\logs\` |
| `--backup` / `--backup=on` | Создать резервную копию `.bak` перед изменением |
| `--backup=off` | Явно отключить резервные копии |
| `--aggressive-pdf` | Оставлен для совместимости и ни на что не влияет: PDF всегда очищается полностью |
| `--wipe-fs`, `--wipe-fs-timestamps` | Сбросить даты создания, изменения и доступа файла на `1980-01-01 UTC` |
| `--audit <files>` | Проверить файлы на признаки метаданных без очистки |
| `--install` | Установить приложение в профиль пользователя и добавить интеграцию с Проводником |
| `--uninstall` | Удалить приложение и интеграцию с Проводником |
| `--diagnostics` | Проверить доступные точки интеграции с Проводником |
| `--help`, `-h` | Показать справку |

Коды возврата при очистке:

- `0` - все файлы обработаны успешно;
- `1` - часть файлов обработана, часть завершилась ошибкой;
- `2` - ни один файл не обработан или команда вызвана неверно.

В режиме `--audit`: `0` — проверенные признаки не найдены, `1` — найдены метаданные, `2` — ошибка проверки или неподдерживаемый формат. Аудит принимает папки и флаг `--log`, не создавая отчёты рядом с документами.

Повторяющиеся пути обрабатываются один раз. Неизвестные параметры отклоняются до очистки. Для имени файла, начинающегося с дефиса, используйте `-- <имя>`.

## Сборка из исходников

Требуется .NET 8 SDK. Для Windows-сборки с macOS используйте полный SDK из `dotnet-install.sh`, потому что brew-версия может не содержать Windows Desktop targets.

### Windows exe

```bash
~/.dotnet/dotnet publish MetadataDel.Cli/MetadataDel.Cli.csproj -c Release -r win-x64 \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:SelfContained=true \
  -o ./publish
```

### macOS CLI

Apple Silicon:

```bash
~/.dotnet/dotnet publish MetadataDel.MacCli/MetadataDel.MacCli.csproj -c Release -r osx-arm64 \
  -p:PublishSingleFile=true \
  -p:SelfContained=true \
  -o ./publish-mac
```

Intel:

```bash
~/.dotnet/dotnet publish MetadataDel.MacCli/MetadataDel.MacCli.csproj -c Release -r osx-x64 \
  -p:PublishSingleFile=true \
  -p:SelfContained=true \
  -o ./publish-mac-x64
```

Быстрый запуск на macOS во время разработки:

```bash
bash scripts/mac/mdel /path/to/file1.pdf /path/to/file2.docx
```

Простая локальная установка на macOS:

```bash
bash scripts/mac/install.sh
```

Скрипт соберёт консольную macOS-версию и установит команды `metadatadel` и `mdel` в `~/.local/bin` без `sudo`.
Также он добавит Finder Quick Action: правый клик по файлу или папке -> **Быстрые действия** -> **Удалить метаданные (MetadataDel)**.

После установки:

```bash
mdel --log --backup=on /path/to/file.pdf
metadatadel --audit /path/to/file.pdf
```

Удаление:

```bash
bash scripts/mac/uninstall.sh
```

Сборка пользовательского macOS DMG:

```bash
bash scripts/mac/build-dmg.sh
```

Артефакт появится в `dist/mac/MetadataDel-<version>-<rid>.dmg`.

Подписанная и нотарифицированная сборка:

```bash
SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" \
NOTARY_PROFILE="metadata-del-notary" \
WAIT_FOR_NOTARIZATION=1 \
bash scripts/mac/build-dmg.sh
```

Подробности по установщику, удалению и запуску без Apple Developer ID описаны в [docs/MACOS.md](docs/MACOS.md).

## Ограничения

- Книги Excel с используемыми внешними формулами или таблицами запросов отклоняются без изменения оригинала: сначала преобразуйте такие данные в значения. Локальные структурированные формулы и VML-кнопки сохраняются.
- Изменения DOCX/XLSX/OLE и PDF готовятся во временном файле рядом с оригиналом. Запрошенная резервная копия обязательна: при ошибке её создания очистка не начинается. Повторные копии получают имена `.2.bak`, `.3.bak`, не затирая первую `.bak`.
- Символические ссылки не очищаются; при обходе папок переход по ним отключён.
- MetadataDel удаляет известные документные метаданные, но не является криминалистическим инструментом и не гарантирует удаление любой возможной скрытой информации из произвольного файла.
- `--wipe-fs` сбрасывает даты файловой системы, но не удаляет владельца файла, ACL, сетевые атрибуты и свойства, которые хранит Windows или файловый сервер.
- Если PDF открыт другой программой и исходный файл нельзя перезаписать, MetadataDel создаёт очищенную копию рядом: `<имя>.MetadataDel.cleaned.pdf`.
- Скрытый текст Word удаляется. Скрытые листы Excel удаляются, если на них не ссылаются формулы, имена, диаграммы, сводные таблицы или внутренние гиперссылки; иначе лист остаётся (без него книга перестанет считаться), и MetadataDel предупреждает об этом. Скрытые строки и столбцы не удаляются: это сдвинуло бы ссылки в формулах.
- Ссылки на локальные и сетевые файлы (гиперссылки, связанные картинки и объекты, пути в полях INCLUDEPICTURE, INCLUDETEXT, LINK и т. п.) сокращаются до имени файла: абсолютный путь у получателя всё равно не откроется, а раскрывает имя пользователя и структуру папок. Путь, набранный обычным текстом, остаётся — это содержимое документа.
- Кэш сводной таблицы хранит уникальные значения исходных данных. Если источник лежит в самой книге, это его копия. Если источника в книге нет, MetadataDel предупреждает: убрать такие данные можно, только заменив сводную таблицу значениями. Книги со сводными таблицами на внешних подключениях отклоняются без изменений, как и книги с внешними формулами.
- Во встроенной книге Excel (например, данных диаграммы) внешние ссылки и подключения сохраняются, чтобы не сломать диаграмму; об этом выводится предупреждение.
- Метаданные удаляются из изображений JPEG, PNG, JPEG 2000, GIF, WebP и SVG. В TIFF, EMF и WMF они не проверяются.
- Из PDF удаляются закладки, ссылки и теговая структура (доступность для экранных дикторов), потому что в них хранятся служебные данные и аннотации.

## FAQ

**Нужен ли .NET на компьютере пользователя?**

Нет. Релизный `MetadataDel.exe` собирается как self-contained приложение.

**Нужно ли отдельно ставить exiftool?**

Нет. MetadataDel очищает PDF сам. Прежние версии запускали `exiftool`, но для PDF он лишь дописывал новую версию поверх старой, а предыдущая оставалась внутри файла; теперь он не используется и не поставляется.

**Что делает `--aggressive-pdf`?**

Ничего: флаг оставлен, чтобы не ломать существующие скрипты и ярлыки.

**Как проверить, что метаданных не осталось?**

`MetadataDel --audit <файлы или папки>` проверяет файл независимо от очистки: просматривает все части архива DOCX/XLSX (включая встроенные объекты и части без ссылок), все объекты PDF, изображения и внутренние потоки DOC/XLS. Код возврата `1` означает, что что-то найдено.

**Безопасно ли запускать на важных файлах?**

Для важных файлов используйте `--backup`: рядом будет создана `.bak`-копия. Без этого флага MetadataDel перезаписывает исходный файл.

**Что делать, если очистка не удалась?**

Рядом с проблемным файлом создаётся `<имя>.MetadataDel-ошибка.txt` с описанием ошибки.

**Как быстрее очистить десятки файлов?**

Используйте **Отправить -> Удалить метаданные** или передайте папку в CLI. Так файлы обрабатываются одним процессом.
