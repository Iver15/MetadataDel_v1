# Аудит и исправления MetadataDel

Дата: 29 сентября 2026 года. Исходная ревизия: `736ba42`.
Рабочее дерево перед аудитом было чистым. Изменения оставлены локально, без коммита, публикации и изменения установленной программы.

## Область проверки

Прочитаны ядро очистки PDF/OpenXML/OLE, оба CLI, установщики и сборочные скрипты, тесты и документация. Выполнены сборки, регрессионные тесты, smoke-проверки CLI и Finder-обёртки, проверка NuGet и состава дистрибутива. Это инженерный аудит текущего кода; он не доказывает отсутствие любых скрытых данных в произвольных документах и не заменяет проверку выпуска на Windows.

## Результаты проверки

- Исходные 9 тестов проходили. Добавленные первые 9 регрессионных сценариев падали на исходном коде.
- После исправлений: **31/31 тест** в Release, включая 22 новых сценария.
- `dotnet build MetaDataDel.sln -c Release`: успешная сборка обоих CLI и обоих target framework ядра.
- `dotnet publish` для `osx-arm64` и `win-x64` с `--self-contained true`: успешно. macOS-бинарник запускается с `--help`; состав Windows publish проверен.
- `python3 scripts/tests/smoke.py /path/to/dotnet`: CLI и коды возврата Finder проходят.
- Shell-скрипты проходят `bash -n`; native macOS installer собирается Clang для arm64 и x86_64.
- `dotnet list ... --vulnerable --include-transitive --framework net8.0`: известных уязвимых пакетов не найдено. Для multi-target/windows команда SDK возвращает ошибку чтения assets или пустой набор, поэтому это не считается полным результатом аудита Windows-зависимостей.
- Восстановленные 241 файл ExifTool побайтно совпадают с официальным тегом 13.52.
- `git diff --check`: без ошибок.

## Границы проверки и оставшиеся ограничения

- Windows EXE кросс-компилирован, но не запускался на Windows. Работа Проводника, COM и реальная установка/удаление EXE/MSI требуют Windows; проверки добавлены в CI, который здесь не запускался.
- Локальный запуск WiX 5 подтвердил неверный прежний синтаксис `-d...`; после исправления дошёл до platform-specific проверки путей. WiX прямо предупреждает, что поддерживает только Windows, и на macOS отклоняет обычное имя каталога. Это **не успешная сборка MSI**; полный результат проверяется на Windows.
- Native installer собран, но графический install/uninstall и полный Finder workflow не выполнялись. DMG, Developer ID и notarization не проверялись.
- Сохраняется предупреждение NU1701 для старой публичной реализации Word Interop. Основной CLI выбирает OLE cleaner и не использует её. Публичные Interop-классы не удалялись в рамках исправления поведения CLI.
- OLE-тесты проверяют созданные программно контейнеры и сохранность потоков, а не отображение реальных DOC/XLS в Microsoft Office.
- Проверка документов охватывает перечисленные признаки; вложенные изображения, нестандартные расширения форматов и произвольная скрытая информация не считаются полностью проверенными.
