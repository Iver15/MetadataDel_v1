# Аудит и исправления MetadataDel (ноябрь 2026)

Дата: 19 ноября 2026 года. Исходная ревизия: `cc52b7a` (MetadataDel 2.4.1). Результат выпущен как MetadataDel 2.5.0.

## Платформа и зависимости

| Было | Стало | Причина |
|---|---|---|
| .NET 8 (поддержка закончилась 10.11.2026) | .NET 10 LTS (до 11.2028) | Нет обновлений безопасности для .NET 8 |
| `itext7` 7.2.5 + Portable.BouncyCastle 1.8.9 | `itext` 9.8.1.1 + `itext.bouncy-castle-adapter` (BouncyCastle.Cryptography 2.7.0) | CVE-2024-29857, CVE-2024-30171, CVE-2024-30172 в старом BouncyCastle |
| DocumentFormat.OpenXml 3.0.2, OpenMcdf 3.1.4, System.IO.Packaging 8.0.1 | 3.5.1, 3.4.0, 10.0.15 | Актуальные версии |

`dotnet list package --vulnerable --include-transitive`: уязвимых пакетов нет.

## Исправленные дефекты

| Область | Проблема | Исправление |
|---|---|---|
| XLSX | Формула с `://` (например, `HYPERLINK("https://…")`) или структурированная ссылка рядом со ссылкой на лист считалась внешней — книга отклонялась целиком, имена удалялись | Разбор формул: строки пропускаются, внешними считаются только ссылки `[n]Лист!`, `[Книга.xlsx]Лист!`; проверяются также условное форматирование, проверка данных, диаграммы, таблицы запросов |
| XLSX | Скрытый лист с таблицей удалялся, хотя формулы ссылались на таблицу по имени | Имена таблиц учитываются как ссылки на лист |
| XLSX | Битый VML примечаний ронял очистку; `fileSharing` удалялся целиком | VML остаётся с пометкой «не полностью»; удаляется только `userName` |
| DOCX | Снятие обёрток `customXml`/`smartTag` оставляло их свойства внутри абзаца — Word мог считать файл повреждённым | Свойства удаляются до снятия обёртки; проверка OpenXmlValidator |
| DOCX | Удалённый в режиме исправлений абзац оставлял пустой пункт списка; маркеры исправлений таблиц теряли обязательного автора | Поведение «Принять все»: абзац сливается со следующим, ячейки/строки удаляются или объединяются |
| DOCX | Видимый текст удалялся, если стиль абзаца скрывал текст, а стиль символа явно его показывал; картинки удалённого скрытого текста оставались в пакете | Правильный порядок приоритета стилей; неиспользуемые связи с картинками и объектами удаляются |
| DOC | Отрицательная длина в таблице фрагментов вызывала бесконечный цикл; блок дат комментариев читался по неверному индексу FIB (97 вместо 112) | Проверка границ, верный индекс |
| PDF | Все аннотации удалялись, видимые выделения и штампы пропадали | Видимые пометки переносятся в содержимое страницы |
| Все форматы | Признаки «успеха» при оставшихся данных: зашифрованные/повреждённые фрагменты, сбой проверки, копия PDF рядом с неизменённым оригиналом | Новый статус «Очищен не полностью» (`CleanResult.Incomplete`), `[PARTIAL]` в CLI, код возврата 1, отдельное уведомление Finder и состояние в окнах |

## Метаданные, которые теперь удаляются

- **Файловая система:** «Где получен», теги и комментарии Finder (macOS), адрес загрузки в `Zone.Identifier` и прочие NTFS-потоки (Windows). Признак карантина сохраняется. Владелец и группа файла сохраняются.
- **DOCX:** цифровые подписи, служебные данные стандартных блоков (glossary), идентификаторы правок (`rsid`-элементы, `creationId`, `durableId`, `dateUtc`), имена картинок вида `IMG_2031.JPG`, относительные и сетевые пути; ZIP пересобирается без комментариев, дополнительных полей и дат.
- **XLSX:** `xr:uid`, пользовательские представления, пользовательские свойства листов, текст удалённых ячеек в sharedStrings, имя пользователя в `fileSharing`; Power Query и списки источников удаляются с предупреждением.
- **DOC:** неактивная копия служебной таблицы, лист рассылки, конверт письма, сведения о принтере, путь автосохранения, время последнего сохранения, пути внешних файлов, даты в каталоге OLE-контейнера, путь к справке VBA.
- **XLS:** имя в FILESHARING, пути гиперссылок и внешних книг, имена личных представлений, путь к справке VBA.
- **PDF:** EXIF за цепочкой фильтров, `/AF` и `/OPI` во всех объектах, теговая структура (Alt/ActualText), имена слоёв из ресурсов страниц.
- **Изображения:** PNG по белому списку блоков (C2PA и прочие удаляются), посторонние APP0 в JPEG, комментарии JPEG 2000, теги TIFF; HEIC/AVIF с EXIF обнаруживаются.

## Изменения поведения

- Резервные копии сохраняются в личную папку (`~/Library/Application Support/MetadataDel/Backups/<дата>/`, `%LocalAppData%\MetadataDel\Backups\<дата>\`), а не `.bak` рядом с документом. Удаление программы их не трогает.
- Отчёты об ошибках пишутся в папку журналов, а не рядом с документом. Журналы старше 30 дней удаляются; на macOS журналы в `~/Library/Logs/MetadataDel`.
- Коды возврата: `0` — всё очищено полностью, `1` — есть `[PARTIAL]` или `[FAIL]`, `2` — ничего не обработано, `130` — прервано (Ctrl+C/SIGTERM, оригинал не изменён).
- `--audit` дополнительно проверяет атрибуты файла.
- Протокол окна macOS (`--gui-clean`) — версия 2 (`incomplete`, `backupPath`).
