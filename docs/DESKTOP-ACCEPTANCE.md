# MetadataDel 2.4.0 — приёмка desktop-версии

Рабочая ветка `codex/desktop-installation`, база `88724a8`. Результаты относятся к локальной macOS-среде и собранным здесь артефактам. Публичного релиза и изменения main не было.

## Подтверждено

- Сборка всего solution .NET 8: 0 ошибок, 0 предупреждений.
- 66/66 Core-тестов локально, включая GUI-вызовы, исходники при ошибке, backup, аргументы и освобождение файлов после отказа OpenXML.
- CLI smoke: обычные audit/help/error-коды и отдельный JSON-режим.
- Finder wrapper: коды 0/1/2, отдельные аргументы с кириллицей/пробелами/кавычками, неизменный `--log --backup=on`.
- Нативный runner: 6 проверок валидного ответа, предупреждения, неверного пути/версии, ошибки и повреждённого JSON.
- Состояние интеграции: 3 проверки отсутствующих компонентов, полного набора и устаревшего command-path.
- Установка в временный HOME: чистая установка, повторная установка, rollback после отказа helper, удаление с сохранением документов/.bak.
- Ownership: отказ при ссылках на support-файлы, родительском каталоге и внутри workflow; отказ удалять посторонний `mdel`.
- Живое AppKit-окно в текущей тёмной теме: `⌘O`, несколько файлов, нормальный DOCX/повреждённый DOCX/неподдерживаемый TXT, отдельные статусы, блокировка повторной обработки завершённых строк.
- Readback GUI-документа: автор удалён, текст документа сохранён, `.bak` содержит исходные метаданные; повреждённый оригинал не изменён.
- Независимое read-only ревью: два Important воспроизведены и исправлены с RED→GREEN; замечание о состоянии интеграции также исправлено.

## Проверка артефактов

При подготовке релиза первая Windows CI-проверка выявила утечку файлового потока при открытии повреждённого OpenXML-документа. Очистители DOCX/XLSX и аудит теперь явно владеют потоком и закрывают его даже при исключении до создания документа. Регрессионные тесты аудита воспроизвели блокировку на macOS до исправления и прошли после него. Первоначальные локальные артефакты `807fa9c` предшествуют исправлению; для релиза требуются новые сборки CI.

Собраны `MetadataDel-Setup-2.4.0.0.exe`, `MetadataDel-2.4.0-osx-arm64.dmg` и `MetadataDel-2.4.0-osx-x64.dmg`. Итоговые SHA-256 сохранены рядом с дистрибутивами в `dist/desktop-2.4.0/SHA256SUMS.txt`.

Оба DMG прошли `hdiutil verify`, монтирование read-only и проверку версии, архитектуры, helper-скриптов и запуска встроенного CLI. Intel CLI запущен через Rosetta, что не заменяет проверку на Intel Mac. App bundle прошёл `codesign --verify --deep --strict` с ad-hoc подписью. Это не подтверждает публичную нотарификацию.

Для нового MSI-ярлыка задан отдельный HKCU KeyPath согласно [требованию ICE43](https://learn.microsoft.com/en-us/windows/win32/msi/ice43). XML проверен локально; Windows Installer validation остаётся отдельной проверкой на Windows.
