## Решения

- Используются emil-design-eng и better-ui из ~/.codex/skills. CSS-рецепты переведены в нативные AppKit/WinForms средства: системные кнопки и фокус, спокойные поверхности, мгновенные частые взаимодействия, текстовые статусы. Декоративной анимации нет; системные настройки доступности сохраняются.
- Нативные элементы не заменяются самописными анимированными кнопками: предсказуемая работа с клавиатурой важнее CSS scale-рецепта.
- Для сборки используется установленный CLT через DEVELOPER_DIR; глобальные настройки Xcode и лицензия не меняются. SDK .NET устанавливается во временный каталог, не в репозиторий.
- Пересечение задач 1→3: окно только без аргументов. 2→3/4: CleanResult/JSON v1 и outputPath; прежние CLI/Finder не используют JSON.
- Публикация и реальные подписи выполняются только при доступных сертификатах; отсутствие Windows runtime или сертификатов отмечается как граница проверки.

## Прогресс

- Начата проверка базы и установка SDK.

- RED: новые Core-тесты не компилировались до появления интерфейсов; GREEN: 63/63.
- RED: native runner отсутствовал; GREEN: 6 контрактных сценариев.
- RED: интеграционный install-script отсутствовал; GREEN: fresh/reinstall/rollback/uninstall, документы сохранены.
- Живая macOS-проверка: picker по ⌘O, три документа, нормальный DOCX очищен, повреждённый отклонён, TXT не обработан, кнопка повторного запуска выключена.
- Найдено при живой проверке: не было меню «Правка». Добавлено стандартное меню; выбор всех файлов через его пункт проверен, сочетание ⌘A через UI automation не подтверждено. Английская ошибка повреждённого пакета локализована; тест сначала воспроизвёл дефект, затем прошёл.
- Решение: явное создание нового сервиса GUI без переделки существующих CLI-циклов минимизирует риск основному сценарию. Возникает небольшой повтор выбора очистителя; закрыт тестами пяти форматов ядра.
- Решение: macOS runner использует временные файлы с правами 0600 в каталоге 0700 вместо pipes, чтобы исключить блокировку при большом stderr. Файлы удаляются после вызова, постоянной истории нет.

## Независимое ревью и исправления

Read-only reviewer нашёл два Important: запись через symlink в support/workflow и удаление постороннего mdel. Оба воспроизведены тестом (`Unexpected installation over command-path symlink`), затем закрыты общим preflight до мутаций. Проверяются файлы, родители и ссылки внутри workflow; удаление проверяет принадлежность CLI/alias/workflow.

Замечание о ложном статусе неполной интеграции повышено с Minor до Important: правый клик — главный сценарий. Добавлена проверка всех компонентов и command-path; три теста подтверждают отсутствие, целостность и устаревший путь. При неполной установке показывается восстановление.

|---|---|---|
| Запуск значка показывал установку/удаление | Одна рабочая поверхность с выбором документов и результатами | Главная задача доступна сразу; операции установки вторичны |
