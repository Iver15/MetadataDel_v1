## Проверено

- macOS: сборка `.app` и DMG (arm64); UI-, runner-, integration-state, ownership и integration-тесты проходят. В UI-тест добавлена синхронизация флажка между окном и настройками.
- В живом приложении просмотрены главное окно и окно настроек (тёмная тема), синхронизация флажка, раскладка DMG в Finder.
- Windows: `dotnet build` без предупреждений, 66 тестов ядра проходят; установщик собран Inno Setup в Docker (`amake/innosetup`).

Не проверено вживую: окно настроек Windows и мастер Inno Setup на реальной Windows (DPI, High Contrast), светлая тема macOS. Оформление DMG применяется через Finder (AppleScript); без доступа к Finder сборка выводит предупреждение и выпускает DMG без фона.
